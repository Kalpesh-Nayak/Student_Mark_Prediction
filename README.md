# Student Marks Predictor 🎓

## Overview

Student Marks Predictor is a machine learning-based web application designed to estimate students' final academic grades using their personal, educational, family, and lifestyle information. The project combines predictive analytics with personalized, rule-based recommendations to help students identify potential areas for improvement.

## Features

- **Grade Prediction:** Predicts students' final grades on a scale of 0–20 using two regression models.
- **Linear Regression:** Provides grade predictions using a linear regression model.
- **Random Forest Regressor:** Estimates final grades using an ensemble-based machine learning approach.
- **Personalized Recommendations:** Generates suggestions based on attendance, study time, previous grades, recent academic performance, and absences.
- **Interactive Web Interface:** Allows users to enter student information through a structured web form.
- **Prediction Results:** Displays the estimated grades from both models.
- **Responsive Design:** Provides a dark-themed interface with styled cards, animations, and responsive layouts.

## How It Works

Users enter the required student information through the web interface. The Flask backend processes the submitted data and passes it to the trained Linear Regression and Random Forest Regressor pipelines. The application displays both predicted grades and generates rule-based recommendations using selected academic indicators.

## Project Objective

The primary objective is to demonstrate how machine learning can support educational performance analysis through grade prediction and actionable feedback. The application is intended for educational demonstration and should not be treated as a guarantee of actual academic results.

## Future Enhancements

Potential improvements include model performance comparisons, visual analytics, downloadable prediction reports, student performance dashboards, and more advanced recommendation techniques.
